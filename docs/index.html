Engineered for High-Signal Fleet Hygiene

No bloated Electron wrappers, no cloud accounts, and no root-polluted user directories.

01

35+ Package Managers via MPM

Orchestrates Homebrew, Cask, npm, pnpm, bun, uv, pipx, Cargo, Go, RubyGems, Composer, MAS, and APT/APK—automatically filtering out macOS Perl CPAN dual-lived noise.

02

Real-Time OSV.dev Hydration

Concurrently queries OSV.dev batch endpoints and hydrates full vulnerability advisories (CVE IDs, GHSA, RustSec, PySEC, human-readable summaries, and fixed-in versions).

03

Namespace-Aware Privilege Guard

Never runs user-scoped managers (brew, npm, cargo, pip) as root. Escalates only for system paths (e.g. /Library/Ruby/Gems) via Touch ID or native macOS prompts.

04

In-Place Queue Review & Lock

Filter by Critical, High, Safe, Major, or Queued in a single unified table. Execution locks selection controls and streams real-time SSE stdout/stderr logs.

05

Hardened Loopback Security

Binds strictly to 127.0.0.1 with Host-header DNS-rebinding protection, strict Origin CSRF guards, and subprocess argument-injection validation.

06

Single Go Binary + JSONL Audit

React 19 + Tailwind v4 SPA is embedded via //go:embed. Every upgrade and Topgrade sweep is recorded to ~/.local/state/vanguard/history.jsonl.

Multi-Tier Vulnerability Triage

Not all advisories are equal. Vanguard classifies and ranks every outdated package by real CVSS/GHSA severity.

Severity Tier CVSS / Vector Criteria Intelligence Sources Default Behavior
CRITICAL CVSS ≥ 9.0 · Network RCE (AV:N/C:H/I:H) NVD CVE, GHSA, RustSec, PySEC, Go Vuln DB Ranked #1 · Auto-queued · Blocks vg check (exit 1)
HIGH CVSS 7.0 – 8.9 · Remote DoS / Memory Exhaustion NVD CVE, GHSA, OSV Ecosystem Feeds Ranked #2 · Auto-queued · Blocks vg check (exit 1)
MEDIUM CVSS 4.0 – 6.9 · Local / Conditional Exploitation GHSA Moderate, RubySec, npm Audit via OSV Ranked #3 · Highlighted with inline advisory summary
SAFE (MINOR/PATCH) SemVer non-breaking update (< next major) Registry SemVer Delta Ranked #4 · Pre-selected for one-click batch upgrade
CLI & Headless Automation

Styled with the Charm stack (Lipgloss + Bubbles) for interactive terminals and clean CI/cron execution.

Command Description
vg Launch local daemon on 127.0.0.1:9099 and open the embedded Web Control Center
vg -no-web Run daemon in headless background mode without opening a browser window
vg check Scan all managers, hydrate OSV advisories, print severity table, exit 1 on Critical/High CVEs
vg apply [--cve-only | --all] Apply safe or security-only updates directly in the terminal with live streaming progress
vg sweep Trigger deep system-wide Topgrade sweep (git repos, language toolchains, firmware)
vg history Inspect persistent JSONL upgrade audit trail (~/.local/state/vanguard/history.jsonl)
