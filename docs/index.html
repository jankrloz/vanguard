Unified Vulnerability & Update Intelligence

Know every outdated dependency across your machine, its exact security impact, and whether upgrading is safe or breaking.

01

Authoritative Vulnerability Engines

Correlates outdated packages against OSV.dev, GitHub Security Advisories (GHSA), SBOM scans via osv-scanner and trivy, and native package manager audits (npm audit, pip-audit).

02

Inline Summaries & Remediation Targets

Displays human-readable vulnerability descriptions, package descriptions, CVSS severity badges, and exact patched versions (Fixed >= X.Y.Z vs. unpatched Zero-Day) in both CLI and Web views.

03

Safe Minor/Patch vs. Major Guards

Automatically separates non-breaking Safe (Minor & Patch) updates from Major Breaking releases, with package pinning to hold back specific dependencies when needed.

04

35+ Package Managers Unified

Scans and upgrades Homebrew formulae and casks, npm, pnpm, yarn, bun, pip, pipx, uv, uvx, Cargo, Go, RubyGems, gcloud, Composer, Mac App Store, APT/APK, and full-system Topgrade sweeps.

05

Interactive Web Dashboard

Filter updates by Vulnerabilities, Safe, Major Breaking, Pinned, or Queued, inspect advisory links, and stream live upgrade output in real time.

06

Headless CLI & Persistent Audit Log

Run vg check as a CI or terminal security gate, execute batch upgrades with vg apply, monitor continuously with vg monitor, and audit every version change in history.jsonl.

Severity & Update Risk Classification

Not all advisories or version bumps carry the same risk. Vanguard ranks every package by exploitability and SemVer impact.

Classification Severity / SemVer Criteria Intelligence Sources Default Action
CRITICAL CVSS 9.0 – 10.0 · Remote Code Execution / Auth Bypass OSV.dev, GHSA, Trivy, osv-scanner, npm/pip-audit Ranked #1 · Auto-queued · Fails vg check (exit 1)
HIGH CVSS 7.0 – 8.9 · Denial of Service / Privilege Escalation OSV.dev, GHSA, Trivy, osv-scanner, npm/pip-audit Ranked #2 · Auto-queued · Fails vg check (exit 1)
MEDIUM / LOW CVSS 0.1 – 6.9 · Local or Conditional Exploitation OSV.dev, GHSA, RubySec, PySEC, RustSec, native audits Ranked #3 · Auto-queued · Inline summary & fixed version
SAFE (MINOR / PATCH) Backwards-compatible SemVer update (< next major) Package Registry SemVer Delta Ranked #4 · Pre-selected for batch upgrade
MAJOR BREAKING Major SemVer increment with potential breaking changes Package Registry SemVer Delta Unselected by default · Requires explicit opt-in

CLI & Headless Workflows

Operate interactively from the Web Dashboard or automate checks and upgrades directly from the terminal.

Command Description
vg Launch the local server and open the interactive Web Dashboard
vg -no-web Run the local server in headless background mode without opening a browser
vg check [--security-only | --manager <id>] Scan all managers, run OSV/Trivy/osv-scanner/native audits, print aligned report, exit 1 on CVEs
vg apply [--security-only | --all | -y] Apply safe or security-only updates in the terminal with live progress and post-upgrade verification
vg sweep Run a deep system-wide Topgrade maintenance sweep across repositories, toolchains, and caches
vg history [--limit <n>] Inspect the local upgrade audit trail (~/.local/state/vanguard/history.jsonl)
vg monitor [--interval 1h] Continuously poll for newly published vulnerabilities with desktop alert notifications
